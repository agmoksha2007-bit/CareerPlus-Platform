# CareerPulse

## Vision
CareerPulse is an AI-powered career guidance and placement preparation platform that helps students discover suitable career paths, prepare for placements, build ATS-friendly resumes, practise aptitude and coding, generate portfolios, track progress, and receive personalised guidance through an AI Mentor.

## Tech Stack

Frontend:
- React (Vite)
- Tailwind CSS
- Framer Motion

Backend:
- FastAPI
- Python

Database:
- MongoDB Atlas

Authentication:
- JWT
- Google OAuth
- GitHub OAuth

Deployment:
- Vercel (Frontend)
- Railway or Render (Backend)
- MongoDB Atlas
